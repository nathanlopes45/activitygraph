Principles

Privacy isn't a setting here — it's the architecture

The design choices that make the whole thing safe to point at your own household.

No payload is ever stored

Only 5-tuple flow metadata and the DNS / TLS-SNI hostname already visible in transit — read in the clear, no decryption, no content. What you watched is a category, never a URL history.

No external calls, by default

MAC-vendor lookup uses a bundled offline table — there is no "what site is this IP" service. Active probing (ARP sweep, name resolution) is opt-in, every one of it.

The AI stays on the box

The long-tail classifier talks to a local Ollama model on localhost, only for domains the rules missed, and fails open to "Uncategorized" rather than reaching for a cloud API.

Honest time math

Overlapping activity counts once. A phone and a laptop both streaming 10:00–10:30 is 30 minutes of a person's life, not 60 device-minutes — both figures reported, neither invented.

Run the real dashboard in one command

This page is a static readout; the launcher below serves the interactive dashboard on your own machine — same data, real filters, drill-downs and the live activity graph.

# from the repo root, inside the venv
.venv\Scripts\python.exe demo\serve_demo.py

# then open http://127.0.0.1:8420

Windows PowerShell shown. On macOS / Linux use .venv/bin/python demo/serve_demo.py. No root, no real capture — the synthetic household runs through the shipping pipeline and server.

What's under the hood

Python · FastAPI · a dependency-free single-page frontend · SQLite for history · scapy for live capture · a pluggable local-LLM fallback. The demo adds only its synthetic input; every stage that processes it ships in the project.
